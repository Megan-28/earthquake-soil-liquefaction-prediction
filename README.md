# Prediction of Earthquake-Induced Soil Liquefaction Using Hybrid Wavelet Neural Network and Particle Swarm Optimization

## Overview

Soil liquefaction is a geotechnical phenomenon in which saturated soil loses strength and stiffness during earthquake-induced shaking. This project explores a hybrid machine learning approach to predict earthquake-induced soil liquefaction using a **Wavelet Neural Network (WNN)** and **Particle Swarm Optimization (PSO)**.

## Objectives

- Predict the occurrence of earthquake-induced soil liquefaction.
- Apply a Wavelet Neural Network to model complex relationships in soil and earthquake-related data.
- Use Particle Swarm Optimization to optimize the model parameters.
- Evaluate the model's predictive performance using appropriate metrics.

## Methodology

1. Data collection and preprocessing.
2. Feature selection and preparation.
3. Wavelet Neural Network development.
4. Particle Swarm Optimization for model optimization.
5. Model evaluation and performance analysis.
